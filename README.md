# ThinkHigh - Laptop Store Website

A responsive multi-section website for a fictional laptop store. Built as a frontend practice project to improve HTML, CSS, and Bootstrap skills.

## Features

- Product showcase with cards
- Laptop comparison table
- Image gallery
- Order form
- Fully responsive design
- Mobile-friendly navigation with Bootstrap hamburger menu

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5

## Sections

- Home
- Products
- Compare
- Gallery
- Order

## How to Run

1. Clone the repository
2. Open `think.html` in your browser
